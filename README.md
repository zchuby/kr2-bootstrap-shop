# Гардероб — версия на Bootstrap

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка». Это отдельная
реализация той же предметной области, что и в КР-1 (интернет-магазин одежды «Гардероб»),
но интерфейс построен на CSS-фреймворке Bootstrap 5.

## Используемый фреймворк

Bootstrap 5.3.8.

## Подключение Bootstrap

Bootstrap подключён **локально**, без CDN. Файлы фреймворка размещены в папке `vendor/bootstrap/`.

Используются:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Собственный файл `css/custom.css` подключается **после** Bootstrap, чтобы иметь
возможность точечно переопределять стандартные стили.

## Ссылка на опубликованный проект

GitHub Pages: https://zchuby.github.io/kr2-bootstrap-shop/

## Структура проекта

- `index.html` — главная: hero-блок, преимущества, популярные товары;
- `catalog.html` — каталог: сетка карточек, значки, фильтры, пагинация;
- `product.html` — страница товара: характеристики, цена, accordion;
- `order.html` — форма заявки на Bootstrap-компонентах;
- `contacts.html` — контакты и форма обратной связи;
- `css/custom.css` — фирменные стили поверх Bootstrap;
- `vendor/bootstrap/` — локальная копия Bootstrap 5.3.8;
- `images/` — изображения товаров;
- `.gitignore` — исключения для Git;
- `README.md` — описание проекта.

## Реализованные Bootstrap-компоненты

- `container`, `row`, `col-*`, `row-cols-*`, `g-4` — адаптивная сетка;
- `navbar` с мобильным раскрывающимся меню (`navbar-toggler`);
- `card` — карточки товаров;
- `btn`, `btn-primary`, `btn-outline-primary` — кнопки;
- `badge` — значки «Хит», «Новинка», «Скидка»;
- `alert` — информационные сообщения;
- `modal` — модальное окно быстрой заявки (атрибуты `data-bs-toggle` / `data-bs-target`);
- `form-control`, `form-select`, `input-group`, `form-check` — элементы форм;
- `accordion` — блоки характеристик и подсказок;
- `breadcrumb` — навигационные крошки;
- `pagination` — постраничная навигация каталога;
- `list-group`, `table` — список контактов и таблица характеристик.

## Самостоятельные доработки

- Bootstrap подключён локально из `vendor/bootstrap/` — работа без CDN;
- добавлена пятая страница `contacts.html` с формой обратной связи;
- использованы дополнительные компоненты: `accordion`, `breadcrumb`, `pagination`, `list-group`;
- каталог дополнен фильтрами-категориями и постраничной навигацией;
- фирменный стиль через CSS-переменные в `custom.css` (цвет кнопок, hero-градиент,
  hover-эффекты карточек);
- адаптивность проверена на ширине от 360 px до десктопа.

## Как проверить

1. Открыть ссылку GitHub Pages.
2. Сузить окно браузера до ширины телефона — меню превращается в «гамбургер»,
   карточки перестраиваются в одну колонку.
3. Нажать «Заказать» на любой карточке — откроется модальное окно.
4. Открыть страницу товара и раскрыть accordion-разделы.
5. Открыть страницу заявки и просмотреть поля формы.
